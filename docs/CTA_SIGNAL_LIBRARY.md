## 总计：25 个信号（7+4+5+3+3+3），已测 5 个，未测 20 个

## 实施架构

```
第一层：逐信号×逐品种测试（25×20=500 组合）
  → 每个信号在每个品种上的年化/夏普/胜率
  → 用前半(2015-20)筛选，后半(2021-26)验证
  
第二层：品种-信号匹配矩阵
  → 每个品种选出最优2-3个信号
  → 检查匹配的稳健性（前半选的后半仍有效？）
  
第三层：组合构建
  → 品种内：最优信号加权
  → 品种间：等风险分配 + vol target
  → 整体：回撤控制
```

## 诚实限制

| 问题 | 影响 | 缓解 |
|---|---|---|
| 多重检验 | 500组合中5%假阳性=25个虚假信号 | FDR校正 + 严格前/后半验证 |
| 信号相关性 | T1三套参数高度相关 | 族内去重（每族选最优1-2个代表） |
| 过拟合风险 | 前/后半分界点本身可能过拟合 | 滚动窗口交叉验证 |
| 数据窥探 | 反复测试同一数据 | 预注册先写死所有信号定义 |
