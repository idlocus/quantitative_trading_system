## 1. 核心理念

### 技术分析三大假设
1. **市场行为反映一切** — 价格消化所有已知信息。技术分析师关注"市场如何移动"而非"为何移动"
2. **价格沿趋势移动** — 趋势在反转前保持不变。技术分析师顺势交易
3. **历史会重演** — 价格形态和信号会重复，基于人性（恐惧与贪婪）

### 第四原则：纪律优先于信念
- 策略规则优先于当前判断
- 定期评估策略有效性
- 限制持仓时间，避免"亏损死扛"

### 分析前先问
- 市场处于趋势还是震荡？
- 是领先还是滞后？
- 是否涨/跌太快太远？

## 2. 多时间框架分析 (MTFA)

### 时间框架层级
| 时间框架 | 用途 | 说明 |
|---------|------|------|
| 月线 | 定义主要趋势 | 长期方向锚点 |
| 周线 | 细化主要趋势 | 识别中期形态 |
| 日线 | 战术执行 | 精确定位入场/出场 |

### 趋势判断规则
- **上升趋势**: 均线多头排列 (短期 > 中期 > 长期)
- **下降趋势**: 均线空头排列 (短期 < 中期 < 长期)
- **震荡**: 价格在均线间来回穿梭

### 时间框架一致性
- 多时间框架方向一致时 → 信心增加
- 多时间框架冲突时 → 降低仓位或观望

## 3. 移动平均线 (MA)

### 常用周期
| 类型 | 周期 | 用途 |
|------|------|------|
| 短期 | 10, 20 | 战术操作 |
| 中期 | 50, 100 | 确认趋势 |
| 长期 | 150, 200 | 定义主要趋势 |

### 使用规则
1. **价格 vs MA**: 价格在 MA 上方看涨，下方看跌（5个条件）
2. **MA 斜率**: 正斜率看涨，负斜率看跌（5个条件）
3. **金叉/死叉**: 短周期上穿/下穿长周期
4. **MA 交叉信号**: Golden Cross / Death Cross

### Golden Cross / Death Cross 实证 (S&P 500)
- **Golden Cross** (50日MA上穿200日MA):
  - 1927年以来49次信号，25-80天后上涨概率59-73%
  - 200日MA正斜率时，76%概率25天后上涨
- **Death Cross** (50日MA下穿200日MA):
  - 不是显著的 bearish 信号，30天后反而63%概率上涨

### MA 作为支撑/阻力
- 上升趋势中 MA 提供支撑
- 下降趋势中 MA 提供阻力

## 4. MACD (移动平均收敛/发散)

### 计算公式
- **MACD线** = 12周期EMA - 26周期EMA
- **Signal线** = MACD的9周期EMA
- **Histogram** = MACD - Signal

### 信号类型
1. **MACD 交叉**: MACD 上穿/下穿 Signal
2. **零轴交叉**: MACD 上穿/下穿零轴
3. **背离**: 价格创新高但 MACD 没创新高（看跌）
   - **三峰顶背离** = 强反转信号
   - **双底底背离** = 买入信号
   - **三底底背离** = 更强买入信号

###Histogram 提前预警
- 价格创新低但 Histogram 更高 → 即将出现金叉

---

## 5. RSI (相对强弱指数)

### 公式
RSI = 100 - (100 / (1 + RS))
其中 RS = 平均涨幅 / 平均跌幅（通常14周期）

### 关键水平
| 水平 | 信号 |
|------|------|
| >70 | 超买，可能回调 |
| <30 | 超卖，可能反弹 |
| >80 | 极端超买 |
| <20 | 极端超卖 |

### RSI 背离（最重要的信号）
- **底背离**: 价格新低但 RSI 更高 → 买入
- **顶背离**: 价格新高但 RSI 更低 → 卖出
- **三峰/三底背离**: 比双峰/双底更强

### 常见误解
- 超买不意味着立即下跌
- 趋势中 RSI 可以长时间维持超买/超卖
- 背离是预警信号，不是立即反转信号

## 6. 随机指标 (Stochastics)

### 计算
- **%K**: 当前收盘价与N周期最低价的差 / N周期最高价与最低价的差
- **%D**: %K的移动平均

### 信号
- %K 和 %D 进入超买区(>75) → 警惕回调
- %K 下穿 %D → 卖出信号
- %K 和 %D 进入超卖区(<25) → 关注反弹
- %K 上穿 %D → 买入信号

---

## 7. 布林带 (Bollinger Bands)

### 计算
- 中轨 = N周期SMA
- 上轨 = 中轨 + K × 标准差
- 下轨 = 中轨 - K × 标准差

### 信号
- **%B > 0.9**: 价格触及上轨，可能回调
- **%B < 0.1**: 价格触及下轨，可能反弹
- **带宽 < 2%**: 波动率低，预示突破

---

## 8. ATR (平均真实波幅)

### True Range 计算
取以下最大值:
1. 当日最高 - 当日最低
2. |当日最高 - 前日收盘|
3. |当日最低 - 前日收盘|

### 用途
- **动态止损**: 止损设于入场价 ± 2×ATR
- **ATR 通道**: ATR值加减到前日高低点形成交易通道
- **趋势确认**: ATR上升确认趋势强度

## 9. DMI + ADX

### 组成
- **+DMI**: 跟踪更高高点
- **-DMI**: 跟踪更低低点
- **ADX**: 衡量趋势强度

### ADX 水平
| ADX | 市场状态 |
|-----|----------|
| >25 | 趋势确认 |
| >40 | 极强趋势 |
| <20 | 震荡/无趋势 |
| 20-25 | 过渡区 |

### 信号
- +DMI 上穿 -DMI → 趋势向上
- -DMI 上穿 +DMI → 趋势向下
- ADX > 25 + DMI金叉 → 买入确认

## 10. Ichimoku Cloud (一目均衡表)

### 五条线
1. **转换线 (Tenkan-sen)**: 过去9周期高低中值
2. **基准线 (Kijun-sen)**: 过去26周期高低中值
3. **先行线1 (Senkou A)**: (转换线+基准线)/2，向前26周期
4. **先行线2 (Senkou B)**: 过去52周期高低中值，向前26周期
5. **滞后线 (Chikou)**: 当前收盘价，向后26周期

### 信号
- **价格在云上**: 趋势向上
- **价格在云下**: 趋势向下
- **云向上收窄**: 上涨趋势确认
- **转换线上穿基准线**: 买入信号
- **延迟线在价格上方**: 阻力

## 11. 支撑与阻力

### 识别方法
1. **历史高低点**: 重复测试的水平
2. **均线**: 动态支撑/阻力（20/50/200日MA）
3. **布林带**: 轨道支撑
4. **斐波那契回撤**: 23.6%, 38.2%, 50%, 61.8%

### 角色互换
- 阻力突破 → 变成支撑
- 支撑跌破 → 变成阻力

### 趋势线规则
- 至少2个测试点
- 30-50度斜率最佳
- 超过6个月的趋势线更有价值

### 趋势线突破确认
1. 收盘价突破至少1%
2. 成交量大于平均
3. 连续K线收于线下
4. 突破后回撤测试失败

## 12. 斐波那契

### 关键比率
| 比率 | 用途 |
|------|------|
| 23.6% | 浅度回撤 |
| 38.2% | 中度回撤 |
| 50.0% | 心理水平 |
| 61.8% | 黄金回撤（最重要） |
| 76.4% | 深度回撤 |

### 应用
- **回撤目标**: 预测回调可能止步的位置
- **扩展目标**: 测量从趋势起点到终点的距离，从突破点投影
- **预测**: 多个斐波那契水平重叠处信号更强

## 13. 形态识别

### 反转形态
| 形态 | 信号 |
|------|------|
| 双重顶 | 看跌 |
| 双重底 | 看涨 |
| 头肩顶 | 强看跌 |
| 头肩底 | 强看涨 |
| 三重顶/底 | 极强反转 |

### 目标计算
- **双重顶**: 高度 = 顶 - 颈线，目标 = 颈线 - 高度
- **头肩顶**: 高度 = 头 - 颈线，目标 = 颈线 - 高度

### 中继形态
- **三角形**: 收敛后通常延续趋势
- **旗形/楔形**: 短暂整理后延续

## 14. Elliott Wave 基础

### 五浪模式
```
上升: 浪1 → 浪2 → 浪3 → 浪4 → 浪5
      ↑     ↑     ↑     ↑     ↑
      推动  回调  最强  回调  最后一涨
      (低)  (深)  (长)  (浅)  (冲)
```

### 三条规则
1. 浪2不能跌破浪1起点
2. 浪3不是最短的（通常最长）
3. 浪4不能与浪1重叠

### 回调深度
- 浪2通常回调浪1的61.8%
- 浪4通常回调浪3的38.2%
- 交替出现：浪2深回调，浪4浅回调

## 15. 市场广度

### A/D 线 (Advance/Decline)
- 上涨股票数 - 下跌股票数
- **顶背离**: 指数创新高但A/D线没跟上 → 看跌
- **底背离**: 指数创新低但A/D线没创新低 → 看涨

### 52周新高/新低
- 上涨趋势中新高比例增加 → 确认健康
- 下跌趋势中新低比例增加 → 确认弱势

### 百分比 stocks above MA
- % stocks above 200MA > 50% → 趋势向上
- % stocks above 200MA < 50% → 趋势向下

## 16. 季节性

### 月度规律
| 月份 | S&P 500 | 10年期国债收益率 | 美元 |
|------|---------|----------------|------|
| 1月 | +1.23% (63%) | -2bp | 上涨 |
| 4月 | +0.90% (60%) | +7bp | 上涨 |
| 5-10月 | 最低迷 | — | — |
| 11月-4月 | 最强 | — | — |

### Sell in May 的真相
- 5-10月历史平均收益最低
- 但不是"5月卖出"，而是"7-8月卖出"
- 8-10月是最弱3个月
- **"sell in August, buy Halloween"** 更准确

### 总统周期
- 年3和年4最强（平均收益10-13%，85%概率上涨）
- 年2（第一任期）最弱
- 年2（第二任期，即年6）反而强（平均+11.9%，85%上涨）

## 17. 风险管理

### 止损设置
- **固定止损**: 入场价 ± 2×ATR
- **支撑止损**: 关键支撑位下方
- **移动止损**: 跟随价格创新高/低

### 仓位计算
```
仓位 = (账户2%风险) / (入场价 - 止损价)
```

### 风险收益比
| 比率 | 评估 |
|------|------|
| ≥3:1 | 优秀 |
| 2:1 | 良好 |
| 1.5:1 | 一般 |
| <1:1 | 避免 |
