## 策略规则（一条规则）

**当某品种的20日波动率处于过去250日最低20%分位时，按20日均线方向开仓。波动率离开压缩区即平仓。**

具体逻辑：
```
1. 计算20日滚动波动率 = 过去20天日收益标准差 × √252
2. 计算该波动率在过去250日中的分位数
3. 如果分位数 < 20% → 信号激活（压缩状态）
4. 方向 = 收盘价 vs 20日均线的位置
   - 收盘 > MA20 → 做多
   - 收盘 < MA20 → 做空
5. 波动率分位数回到 20% 以上 → 平仓（空仓等待下一次压缩）
```

## 仓位管理

- **品种间**：等权分配（各占总资金 1/6）
- **组合波动率目标**：15% 年化
- **杠杆**：不超过 2 倍
- **空仓时**：全部资金放货币基金/逆回购

## 每日流程

```
15:30 收盘后 → 运行 python scripts/run_cta_daily.py
  → 查看 runtime/cta_daily/今日日期.md
  → 如果有信号变化 → 次日开盘执行
  → 如果无变化 → 不操作
```

## 风险提示

1. **胜率低（32%）**：大部分交易是亏损的，利润来自少数大趋势
2. **空仓期长（82%）**：需要耐心等待压缩窗口
3. **可做空**：与A股策略不同，可以做空（需要期货账户）
4. **杠杆风险**：期货有杠杆，需要严格控制仓位
5. **历史不代表未来**：策略基于2015-2026回测，市场结构可能变化
