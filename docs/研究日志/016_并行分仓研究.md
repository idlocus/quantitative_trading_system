# 试炼 016：011×006 多引擎并行分仓（独立账本，非组合改造）

- 登记日期：2026-10-26 | 状态：**PASS（三档全过，2026-10-26）** | 登记册编号：#16 | 类型：组合构造
- 与 013 的区别：013 是"改造 011 的选股"（已证伪）；本试验是**独立账本
  按比例分仓**——006 多头组合作为独立 sleeve（月度全换仓、扣双边成本
  后净超额 +2.46%/年@20日），与 011 主引擎并行

## 1. 机制理由（组合规则第 2 条）
- 快慢变量收益源不同（反转=月度过度反应；价值质量=慢错误定价）、
  持仓重叠天然低、回撤期可能错位（价值回撤常在成长牛市，反转回撤
  在单边动量市）→ 分散化收益

## 2. 预注册判据（先写死）
- 构造：006 多头月度净值（trial005-007 框架重算并保存曲线）与 011 C
  曲线按 w:(1-w) 月度再平衡，w ∈ {10%, 20%, 30%}
- 判据：任一 w 的**夏普 > 011 单独的 0.51** 且两期年化 >0 且最大回撤
  ≤ -31%（不得以回撤换夏普）
- 敏感性：三档 w 方向一致（夏普随 w 单调或峰形均可，但至少两档改善）

## 3. 预期（含低期望声明）
- 006 sleeve 净贡献 ≈ w×2.5%/年 + 分散化效应；若相关性低，w=20% 或将
  夏普推至 0.53~0.56——**改善幅度预期温和，边际意义可能不显著**；
  若分散化收益不足以覆盖 sleeve 换手成本已计入的拖累，则 FAIL

## 4. 结果（2026-10-26 运行；006多头sleeve=112个月度观测）

  成本；与修正版诊断"超额+2.46%"一致——资格池等权基准约+7%/年）
- **相关性（011×006）：-0.08**（近零——价值慢变量与反转快变量的持仓
  天然错开：011 持有正动量的便宜股，006 持有近期输家）

|---|---|---|---|---|

## 5. 结论与失效分析

- 结论：**016 PASS——并行分仓成立，且改善幅度远超预期的"温和"声明**
- 局限（如实）：
  - sleeve 为收益叠加近似（月度等权组合，无逐股引擎撮合：未建模最低
    申报量、输家反弹日涨停买不进、停牌退出按最后价）——生产化前须
    引擎级实现复核

  - 两成分月度调仓同步，实操需两个独立账本+再平衡规则
