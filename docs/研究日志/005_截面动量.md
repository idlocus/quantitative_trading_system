# 试炼 005：截面动量（6-12 月，独立信号）

- 登记日期：2026-10-26 | 状态：待测 | 登记册编号：#5 | 类型：选股因子
- 备注：旧项目曾有 RPS/动量叠加类裁决，按研究重置协议降级为历史记录，
  本试验为截面动量作为**独立选股信号**的首次从零检验，不继承任何结论。

## 1. 假设与经济理由
- 机械化：factor = 过去 252 交易日收益、跳过最近 21 日（12-1 动量）；
  月末计算，全市场 PIT 池（主板+创业板+科创板，非ST，有价格），十分位组合
- 经济理由：投资者对信息反应不足 + 资金流入赢家缓慢 → 强者恒强在中期
  延续；对手盘 = 对基本面变化调整慢的资金。A股散户结构应放大反应不足
  （但反转文化可能压制——正因此值得检验）

## 2. 预注册判据（先写死）
- 组合：月度等权 Q10（动量最高）− Q1（最低）价差，两期
  （2017-2021 / 2022-2026）年化价差同号为正；成本后（单边 0.25%
  × 月换手）仍为正
- IC：月度 rank IC 均值 |t| ≥ 2（两期分别报告，合并 t 为主判据）
- 敏感性：动量窗 12-1 主判据；6-1 / 12-1 / 18-1 三档同号
- 失败四类归因沿用模板

## 3. 预期
- 若有效：Q10−Q1 年化 +4% ~ +10%（文献常态量级）；IC 0.02~0.05
- 噪音形态：价差集中于个别月份/年份；或仅在某一期存在
