## 1. 假设与经济理由
- 机械化（=生产形态，不改任何参数）：质量过滤（ROE>8% 且 D/E<65%）
  + 价值合成（ep/bp/sp 等权）+ 0.2 权重动量叠加 + Top100 等权月调
- 经济理由：追逐热门的资金给"便宜且持续赚钱"的个股留错误定价；
  质量过滤剔除价值合成的天然陷阱（伪便宜）。对手盘=追热点的资金
- 宇宙：PIT 滚动全市场（主板+创业板+科创板，北交所默认排除）——
  **与旧固定池回测的本质区别**；数据缺口先补齐再测（不降级口径）

## 2. 预注册判据（先写死；C 口径=无闸门干净信号）
1. 两期（2017-21 / 2022-26）年化收益均 > 0（同号）
2. 全期夏普 > 0.4（绝对口径：须显著跑赢现金）
3. 诊断（不进判据）：超额 vs 同宇宙全池等权（选股能力辨析）、
   回撤/最差单年、300/500/1000 参照
- A 口径（含闸门/重入）为生产语义后续项——C 口径失败则 A 无从挽救
- ±北交所消融臂：主口径跑完后同管道加北交所重跑，两期同号裁决宇宙

## 3. 预期
- 若现行形态成立：两期年化 +5% ~ +15%，全池等权超额为正
- 噪音形态：仅靠某一期或某一年（如 2024-09）贡献；全池超额 ≈ 0
  （=旧知识"行业内选股≈0"在新尺上复现）

## 4. 结果（2026-10-26 运行；PIT 滚动宇宙 5469 只，C 口径）

- 最差单年 -28.8%（2018）；分年度：2018 -29% / 2022 -6% / 2026 -8%，其余全正
- 参照（年化）：沪深300 +2.28%（e1 +8.1%/e2 -3.4%）| 中证500 +0.70% |
  中证1000 -2.51% —— **策略绝对收益跑赢全部三个规模指数**
- 诊断·全池等权（e1 +32.3%/e2 +6.7%）：**口径声明——此统计参照含新股
  上市后连板的不可买收益，系统性虚高（旧项目 §2.9 教训），不可当可交易
  对照；仅记录。005-007 的"多头净超额"诊断同受此影响，但其判据基于

## 5. 结论与失效分析

- 结论：**011 FAIL（夏普 0.32 < 预注册 0.4 门槛；两期同号为正通过）**
  ——判据先写死，0.32 就是 0.32，不移动门槛
- 归因：**存在但太弱（风险调整后）**
  - [x] 机制在新宇宙上存活：两期一致为正且现代期略强（+4.91%）——
    与全部跟随类信号的时代结构相反，价值/质量是**逆拥挤**家族的
    慢变量成员（与 006 快变量互补的形态暗示）
  - 绝对收益跑赢 300/500/1000，但 -34% 回撤（C口径无闸门）与
    0.32 夏普说明风险调整后吸引力不足——生产形态的 15% 熔断+重入
    协议正是为压缩此回撤存在（A口径为后续生产语义项）
