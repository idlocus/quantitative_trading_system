## 1. 假设与经济理由
- 机械化：factor = 过去 20 交易日收益（负向，跌得多的未来涨）；
  月末计算，全市场 PIT 池（同 005），十分位组合
- 经济理由：散户对消息过度反应 + 涨跌停磁吸效应后的修复；对手盘 =
  追涨杀跌的过度反应资金。A股 T+1 与散户主导是反转的经典土壤
- 与 005 的关系：对立假设并行（反应不足 vs 过度反应），同一框架
  互为证伪——两者可能在不同时间尺度上同时成立（中期动量+短期反转
  是文献常态），各自独立判据
