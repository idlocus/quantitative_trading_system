# 试炼 017：实战策略族（P1-P7，方法论转向）

- 登记日期：2026-10-26 | 状态：进行中 | 类型：程序（含 P1 预注册）
- 背景与转向（用户裁决 2026-10-26）：前期"跟随类全灭、逆拥挤独活"的
  元结论**过度学术化**——每族仅测一个教科书定义即判死刑；判据（两期
  同号+t≥2）杀死了"环境条件化可交易"的信号；宇宙过滤（上市≥12月）
  直接删除了小市值/次新主战场。本程序转向实战口径。

## 方法论修正（修订 000_索引 组合规则之上的判据层）
1. 主判据 = 实战口径：**每笔净溢价 × 频率 = 年化金额**、最大连续亏损、
   容量（成交额约束）、可执行性（涨停买不进/跌停卖不出的剔除规则）
2. **Regime 条件化为一等结果**："信号 X 在环境 Y 下有效"是可交付结论
   （Y 本身必须用可观测变量定义，无未来信息）
3. 两期同号降级为稳健性参考（不再单独构成死刑）
4. 宇宙放开上市时长限制，以流动性/可交易过滤替代；ST 两版都测

## P1 预注册：涨停板次日溢价（首板/二板/三板+）
- 事件：T 日收盘涨停（按板块涨跌幅规则，close/prev_close-1 ≥ 限额-0.3%）；
  连板数 = 连续涨停天数；剔除一字板（open==high==limit，次日买不进逻辑
  同理：T+1 开盘涨停则该事件不可买）
- 买入：T+1 开盘；持有到 T+1 收盘（日内溢价）与 T+5 收盘（延续）
- 成本：单边 0.15%（佣金+冲击，短线高频执行）
- 主判据：各板档的**平均每笔净溢价 × 年事件频率**；regime 拆分：
  高情绪期（P2 指标届时联动）先按简单市场状态（300 的 60 日趋势上下）
  分组报告
- 预期（实战常识先验）：首板次日溢价长期小幅为正但极依赖情绪周期；
  高度板（3板+）溢价高但频率低且尾部大——用分布（中位数/分位）说话

- **全负、两期一致、强市弱市一致**——无差别追板接力在扣成本后是
  结构性亏损游戏（样本 6.6 万，非噪音）
- 分布右偏（P75 +2.9~5.3%）：**事件内选择**是真实游戏——顶部四分位
  事件赚钱，均值被尾部拖死。这正是 P2（情绪周期）要回答的：能否用
  可观测变量事先选出顶部四分位
- 实战结论：打板生态的"傻瓜版"证伪；职业打板者的利润（若存在）必然
  来自事件筛选（题材/席位/情绪位置/流通盘）——P2/P5 的研究对象

## P1 判定：**FAIL（无差别版）——但产出两条实战禁令**：
1. 不要无差别追板（尤其 3 板+ 的 5 日持有：中位 -7.5%）
2. 打板利润若存在，只在事件筛选里——留给 P2/P5
