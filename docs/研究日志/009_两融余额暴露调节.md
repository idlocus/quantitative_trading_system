# 试炼 009：两融余额 → 市场暴露调节

- 登记日期：2026-10-26 | 状态：待测 | 登记册编号：#9 | 类型：资金层·状态信号（择时）
- 数据：Wind `ASHAREMARGINTRADESUM` 全市场融资余额（日频，2010-2026，已验证）

## 1. 假设与经济理由
- 机械化：月末判定——全市场融资余额（两所合计）**20 日净变化率 > 0 →
  下月持有沪深300；否则现金**；单边 0.25%×切换成本
- 经济理由：融资盘是 A 股风险偏好的最直接载体——余额扩张=杠杆资金
  真金白银看多，收缩=去杠杆/强平螺旋（负反馈）。余额是**状态量**
  （非事件量），与已 FAIL 的"跟随事件"信号机制不同
- 预声明风险：本质仍是"跟随资金"，元观察（跟随类信号现代期失效）
  同样适用于此——两期检验将裁决

## 2. 预注册判据（先写死）
- 两期（2017-21 / 2022-26）年化净超额 vs 买入持有 300 均 > 0（同号）
- 最大回撤 < 买入持有的 70%
- 敏感性：余额变化窗 10/20/40 日三档同号
- 失败四类归因沿用

## 3. 预期
- 若有效：年化超额 +2% ~ +6%，回撤显著收窄（杠杆收缩期恰为下跌期）
- 噪音形态：仅在旧年代有效（跟随类失效模式）
