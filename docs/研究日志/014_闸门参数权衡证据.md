## 证据结论（供变更窗口决策，本试验不设判据不选参数）

1. **没有任何已测闸门配置的风险调整表现优于无闸门**（最好 0.37 < 0.51）
2. **收益主杀手是 8% 软限**：关掉它（G2）收益 +31%→+62%。机理：策略
   自然回撤 -31% ≫ 软限 8%，组合**永久活在降仓区**——软限把"回撤控制"
   变成了"永久减仓"（G3/G4 的 2019-26 全年≈0% 是最直观证据）
3. 硬限+重入**不能有效封顶累计回撤**（G2 回撤 -32%≈C）且重入 whipsaw
   仍损 50pp
4. 非单调性：放宽硬限反而更差（G3 < G1）——软硬限交互复杂，网格外推不可靠

## 决策选项（留给用户/变更窗口）
- 维持 G1（回撤 -21% 换 +2.8%/年——为极端尾部保护付费）
- 关软限保硬限（G2：+5.1%/年，回撤 -32%≈无闸门，硬限只防 2018 式崩塌延续）
- 全关（C：+8.0%/年、0.51，裸奔 -31% 回撤）
- 或重新设计风险层（如基于波动率目标而非回撤阈值——未测，需另行登记）
