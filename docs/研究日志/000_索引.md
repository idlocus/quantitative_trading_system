## 组合测试规则（多要素共同作用时如何选择与分析）

1. **单要素先行**：任何要素先按基线四要素独立测试；未通过单测的要素
   不进入任何组合。
2. **组合需独立经济理由**：提出组合时必须书面回答"为什么'一起'优于
   '各自'"——互补机制（不同收益来源 / 低相关 / 覆盖对方弱点）。
   "两个都有效所以拼起来"不构成理由。
3. **组合 = 新试验**：登记新编号、预注册自己的判据。核心判据固定为：
   **组合的风险调整后表现（夏普）必须优于最优单要素**，否则组合无意义。
4. **禁止组合网格穷举**：每提出一个组合都要有第 2 条的机制理由；
   全部组合计入登记册计数（防数据挖矿）。
5. **失效组合同样完整记录**失效分析（模板 §5 同样适用）。
