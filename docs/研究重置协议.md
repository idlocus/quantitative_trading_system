## 硬规则

1. **旧数字不作输入**：任何历史回测数字（包括"+59.0%/+57% 十年锚"、旧主链 §2.8 表、
   消融/归因的具体数值）不得作为新研究的基线、对照或初始化参数引用。
   需要什么数字，由新管道从 `data_cache` 原始数据重新生成。
2. **先定义后运行**：新基线四要素写入下方 §基线定义 后，才允许第一次回测。
   已知的既往缺陷必须在新基线中显式裁决，不允许默认继承：
   - 宇宙：PIT 全市场；须显式决定科创板/北交所是否纳入，并与生产实盘池对齐
     （旧十年回测用 2017 年固定池，不含此后上市股票——回测宇宙 ≠ 实盘宇宙）
   - 区间：2017-01 ~ 至今；切分期 2017-2021 / 2022-2026 两期同号
   - 基准：沪深300 + 可交易等权对照（同约束、无选股能力）
   - 成本：与生产 `estimate_fees` 同源
3. **试验登记从零计数**：每次回测/实验登记 `results/data/trial_registry.json`；
   多重比较防护沿用（参数邻域平滑、两期同号、预注册判据先行）。
4. **预注册纪律不变**：任何假设先写通过/失败标准，再运行。
