## 硬规则

1. **旧数字不作输入**：任何历史回测数字（包括"+59.0%/+57% 十年锚"、旧主链 §2.8 表、
   消融/归因的具体数值）不得作为新研究的基线、对照或初始化参数引用。
   需要什么数字，由新管道从 `data_cache` 原始数据重新生成。
2. **先定义后运行**：新基线四要素写入下方 §基线定义 后，才允许第一次回测。
   已知的既往缺陷必须在新基线中显式裁决，不允许默认继承：
   - 宇宙：PIT 全市场；须显式决定科创板/北交所是否纳入，并与生产实盘池对齐
     （旧十年回测用 2017 年固定池，不含此后上市股票——回测宇宙 ≠ 实盘宇宙）
   - 区间：2017-01 ~ 至今；切分期 2017-2021 / 2022-2026 两期同号
   - 基准：沪深300 + 可交易等权对照（同约束、无选股能力）
   - 成本：与生产 `estimate_fees` 同源
3. **试验登记从零计数**：每次回测/实验登记 `results/data/trial_registry.json`；
   多重比较防护沿用（参数邻域平滑、两期同号、预注册判据先行）。
4. **预注册纪律不变**：任何假设先写通过/失败标准，再运行。

## 假设空间（2026-10-23 修订：全面开放，无禁止清单）

- 任何假设均可测：技术因子、基本面因子、宏观变量、资金面、行为/结构信号（含国家队痕迹）。
  无先验禁区。`docs/events研究方案.md` 的 18 条旧裁决降级为**历史实验记录**
  （可参考其语境，不构成门槛），重测任何方向 = 新试验，计入登记册。
- 每个假设进入登记册需三件套：
  1. **经济理由**——谁在输钱给你（答不出的不测）
  2. **机械化规则**——策略里只能有规则，不能有观点；
     主观判断可指导研究方向，不可进策略
  3. **预注册通过/失败判据**——先写死再跑
- 不可妥协的度量纪律：两期同号 + 试验登记计数 + 预注册先行。
  假设空间越宽，这三样越重要（多重比较防护是数学，不是保守主义）。
- 方法论资产（装置，非观点）：重放引擎、PIT 数据层、数据契约、可交易对照口径。

## 基线定义（2026-10-23 定稿——所有组合级测试的统一尺子）

- **宇宙**：PIT 全市场 = 主板 + 创业板 + 科创板（与实盘一致）；
  北交所默认排除；选股类候选晋级组合级测试时必须附 ±北交所 消融臂
  （两期同号裁决），胜出宇宙 = 回测宇宙 = 实盘宇宙
- **区间**：2017-01 ~ 至今；门槛 = 2017-2021 / 2022-2026 两期同号；
  滚动三年窗口作收益分布诊断；事件研究/统计筛可用更长全样本
  （如 2015 起），但两期切分原则不变
- **判据**：绝对口径——年化收益 / 最大回撤 / 夏普 / 最差单年
- **参照**（仅诊断，不进判据）：沪深300 + 中证500 + 中证1000
  （规模阶梯，辨风格 beta）+ 可交易等权对照（辨选股能力）
- **成本与撮合**：`trading/rules.py` + `estimate_fees` 唯一同源
  （涨跌停/申报单位/费用），股票组合级回测走重放引擎，
  指数/ETF 类走趋势回测管道（成本同源）
