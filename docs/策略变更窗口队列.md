## 新发现（2026-10-21）：实验池对 Wind 终端的隐藏依赖

`list_symbols(as_of=假期日期)` 在 DB 路径恒为 0 行（假期无行情记录）→
历史上所有实验（SIGNAL_START=2017-01-01 元旦）的池**全部静默走了 WindPy
客户端回退**。终端开启时无感知，关闭时链条断裂（今日趋势过滤实验
两轮全零的直接原因）。已加固：双源皆空硬失败 + 实验改用首个交易日
（2017-01-03）走 DB 路径 + 空池断言。
**B6（新增）**：生产每日运行的池同依赖（14:45 时 DB 无当日记录→回退
客户端）——需池缓存机制（用最近成功日的池）。Wind 终端常开（B2）
在此之前是实际上的硬依赖。
