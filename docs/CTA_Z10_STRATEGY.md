## 策略规则

**当品种的20日波动率处于过去250日最低20%分位（压缩状态）时，
该品种产生带方向的信号（方向 = 收盘价相对20日均线的位置，每日跟随）。
全部资金等权摊给当前所有活跃品种（各 1/活跃数）。**

```
1. vol20 = 过去20天日收益标准差；vol_pct = vol20 在过去250日中的分位
2. 压缩状态：vol_pct < 20%；方向 = sign(收盘 - MA20)，每日跟随
   ⚠ 压缩段内价格穿越 MA20 会翻向（登记版语义；"入场锁方向"已证伪）
3. 目标持仓：每个活跃品种 1/n_active（n_active = 当日活跃品种数，
   无活跃品种 → 空仓）
4. 波动分位回到 20% 以上 → 该品种退出；分母随之变化
5. 组合波动率目标 15% 年化（60日实现波动，杠杆上限 2 倍）
```

**成交口径：信号在 t 日收盘后生成，t+1 日开盘执行。
跳空归属：旧仓吃隔夜 gap，新仓吃日内（`research/cta_signal.portfolio_daily`，
与登记回测/日报/网页同一实现）。**

## 历史登记口径 · 为什么不是"只做最强的1个"（登记册180→181 的教训）

| 变体 | 旧口径（信号日收盘换仓，含跳空幻觉） | 次日开盘（可执行） |
|---|---|---|
| Z8 固定1/6槽 | +7.5%/0.78 | +6.8%/0.73/-23.0% |
| **等权摊活跃** | +17.9%/1.08 | **+13.7%/0.88/-22.3%** ✅ |
| TOP1 全给最强 | +19.1%/1.13 | +12.1%/0.77/-27.6% ❌超25% |
| TOP2 最强两个 | +19.6%/1.17 | +15.4%/0.97/-25.7% ❌超25% |

压缩触发后的隔夜跳空系统性利于新仓；旧口径把跳空记给新仓，虚增集中版
~7pp/0.36 夏普。TOP1 深度排序换仓频繁（~48次往返/年），每次换仓让渡
跳空——排序增益被换仓损耗吃光。**"别摊开"（0.73→0.88）成立，
"选最强"在可执行口径下不成立。**
