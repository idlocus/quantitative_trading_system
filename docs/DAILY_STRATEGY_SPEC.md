## 每日流程

**T 日收盘后（信号计算，全部 PIT）**：

1. **候选池**：全部合格股票——
   流动性（20日滚动**中位数**成交额≥2000万）、非ST、上市≥120交易日、数据完备
   （2026-11-19 口径确认：实现自始使用滚动中位数——抗单日异常放量，
   极端放量股票的入池结果与简单均值不同；文档原"均成交额"表述按实现更正）
2. **剔除**（满足任一即出池）：
   - 亏损或盈利覆盖缺失（pe_ttm 缺失）
   - 趋势过热（EXPMA12−EMA50 距离的横截面分位 ≥ 90%）
3. **排序**：score = ( D16分位 + BP分位 ) / 2，从高到低
   - D16 = −ATR14/close（低波动分位，日更新）
   - BP = 1/pb_lf（价值分位，日更新）

**T+1 开盘前（买卖清单生成）**：

| 决定 | 规则 |
|---|---|
| **卖** | 当前持仓中，T 日 score 排名跌出**前 100 名**的 → 全部卖出 |
| **不卖** | 排名仍在前 100 名内的持仓 → 不动 |
| **买** | 排序前 50 名中当前未持有的 → 买入至组合满 50 只 |
| **权重** | 每只目标金额 = 总仓位 × 1/50（等权） |

**风控（guard，逐日）**：
- 总仓位上限 = min(95%, (净值−15%红线缓冲)/(25%冲击假设×净值))
- 单月亏损 15% 或历史峰值回撤 15% → 停止新买入，人工重启
