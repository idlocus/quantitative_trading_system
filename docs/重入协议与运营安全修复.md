## 一、重入协议（定稿：立即重入 + 滚动熔断）

### 两轮十年验证（2017-2026，v2.1.0 唯一实现，引擎修复后）

| 方案 | 十年收益 | 最大回撤 | 判定 |
|---|---|---|---|
| 永久停机（旧生产语义） | -7.2% | -15.0% | 首次硬限后 1939 交易日持币，错过全部复苏 |
| **第一轮：冷却20日+半仓×60日梯度** | **-1.5%** | **-27.6%** | **被数据否决**：回撤段成簇（2018/2020/2022/2024），慢重入系统性实现亏损+错过反弹（2020 年 +1.6% vs 立即重入 +18%） |
| **定稿：立即满仓重入+365日熔断（终跑）** | **+59.0%** | **-24.9%** | **与纯立即重入逐日一致（熔断十年未触发=零成本），Sharpe 0.39** |
| B 纯立即重入（研究对照，无熔断） | +59.0% | -24.9% | 与 A 全等——熔断保护留待尾部场景 |
| C 无闸门 | +56.6% | -34.3% | 闸门代价 -2.3pp 收益、换取回撤浅 9.4pp（Sharpe 0.34 vs 0.39） |
| 等权 / 沪深300 | -14.4% / +29.2% | — | A 超额：vs 等权 +73.4pp、vs 300 +29.8pp |

### 定稿语义（`risk_gate.py` L3.1b，参数在 `trading/config.py`）

```
回撤 ≥15%（锚=全程峰值）→ 硬限清仓（既有）
清仓完成（空仓+liquidate）→
    记录 liq_dates；淘汰 365 日历日窗口外旧记录
    窗口内次数 > REENTRY_MAX_LIQUIDATIONS(3) → 永久停机等人工（L2.7 拦截）
    否则 → 以现金为新锚，立即满仓重入（trade/1.0）
```

- 设计逻辑：数据说明"慢"是纯损耗（快恢复型策略），但纯立即重入在
  2008 式连续崩盘下会无限清仓-重入循环——滚动熔断计数保留尾部风险保护
- `restart_after_liquidation=True` 保留为研究对照（跳过熔断计数）
- 人工重启流程见 `docs/runbook.md`

## 二、Kill Switch fail-safe + 显式注入（P0 #1/#2）

1. `get_state()`：状态文件损坏/不可读 → **HALT_ALL**（原为静默 NORMAL）。
   读不出状态=不知道该不该停，唯一安全的解释是停。
2. 状态显式注入，热路径不读文件：`GateConfig(trading_switch)` /
   `QMTBroker(switch_state)` / `make_broker(..., switch_state)`，
   `run_daily`/`run_live` 启动时读一次注入。
3. 副产品修复：此前 RiskGate 每次 review 读实时开关文件——**回测/重放被
   runtime 开关污染**。注入式隔离后回测与生产开关解耦
   （`test_replay_gate_ignores_ambient_switch`）。

## 三、数据契约（P0 #3 + #8 + #11）

- **软硬分级**（#3）：覆盖率=硬契约（违反拒绝）；数值区间=软契约
  （告警不阻断，进 `warnings`）；ep/bp/sp 值域放宽。
  依据（评审根因 3.4）：不分错误等级的"严谨校验"比没有校验更危险。
- **真实缓存抽样测试层**（#8，`test_data_contracts_sampling.py`，5 项）：
  复权比值形态 / 不复权价水平 / VWAP 单位比值 / 日期有序无未来 / 0 NaN。
  **首轮即抓到真实语义错误**：缓存 `adjclose` 实为 Wind **后复权**
  （S_DQ_ADJCLOSE，锚定上市日），文档一直写"前复权"。收益计算两者等价
  （全部现役消费方只算收益，无水平值滥用），已如实改标注并以测试锁死
  判别式（后复权比值≥1、末端=最大、台阶式）。
- **契约指纹**（#11）：`contracts_fingerprint()` 注入每个工件 `_meta`——
  契约定义变更后跨指纹对比工件可被识别为跨口径。
