# 行业归因结论（进化路线第 1 步，2026-10-15）

> 问题：策略十年超额中，行业配置与行业内选股各贡献多少？
> 数据：A 口径（定稿重入协议）十年工件 daily_holdings + PIT 万得 L2 行业
>（`data/industry_pit.py`，30 行业，2017 池 100% 覆盖）。
> 方法：月度 Brinson-Fachler（117 个月），基准=PIT 宇宙等权，现金月=伪行业。

## 结果

| 分量 | 十年累计 | 判读 |
|---|---|---|
| 策略（Brinson 持仓口径） | +19.4% | 月末静态近似；实际 +59% 的差额来自月内止损/调仓与权重漂移 |
| 宇宙等权 | -13.1% | 与三口径对照的 -14.4% 互证 ✓ |
| **超额** | **+32.4%** | |
| ├─ **行业配置** | **+22.2%** | **占超额 ~69%** |
| └─ **行业内选股** | **-3.0%** | **≈0（正贡献月占比 48%=抛硬币）** |

行业配置 Top：房地产 +7.1%、独立电力 +5.5%、应用软件 +2.4%、机械 +2.1%
（负：技术硬件 -2.3%、化工 -1.9%、半导体 -1.8%）

## 结论：策略的本质是"经由价值因子表达的行业/风格配置"

1. **行业内选股 alpha ≈ 0**。价值/质量分数在全市场选 Top100 的效果，
   体现在"落在哪些行业"（便宜行业整体被超配），而不是"行业里挑谁"。
   与 STAGE_REPORT 旧中性分解（风格 β +60pp、残差 -31~+25pp）互证。
2. **因此不要做行业中性化**——那会剥离唯一的收益来源（旧实验"中性化
   进组合→否决"第三次确认该规律）。行业暴露控制的正确定位是
   **管理集中的行业赌注**（房地产单行业十年 +7.1pp 是赢了，但同类
   集中度也是 2018/2024 回撤的来源），而非消除暴露。
3. 残差 alpha 缺口（"行业内挑谁"）只能靠**新的信息维度**——
   盈利超预期/一致预期修正/另类数据，对应路线第 3 步。

## 使用

- 复现：`python experiments/industry_attribution.py`（复用十年工件，不重跑回测）
- 月度明细：`ai-created/industry_attribution_monthly.csv`
- PIT 行业层：`data/industry_pit.py`（industry_classification /
  industry_names / industry_matrix；万得 L2，ENTRY_DT/REMOVE_DT 口径）

## 注意事项（诚实清单）

- Brinson 为月末静态持仓近似：月内止损/缓冲带调仓的损益不在分解内
  （+19.4% vs +59% 的差额即此，方向与量级结论不受影响）
- 行业内策略收益按持仓等权近似（策略为等权建仓，月内权重漂移未复算）
- 万得 L2 名称部分由最短子代回推（标签用途；归因键是代码）
