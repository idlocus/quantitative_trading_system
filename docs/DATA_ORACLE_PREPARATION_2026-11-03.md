## 港股通历史资格仍未通过

后续口径更新：用户于 2026-11-03 明确接受“当前名单固定用于历史研究”的简化，历史资格不再作为本轮研究阻断项。667 只股票的冻结样本、上市/退市裁剪和偏差标记已另行建立；历史资格验证结果仍为 false。当前规则以 [研究目标与边界](RESEARCH_MANDATE.md) 和 `research/data_policy.json` 为准。下述内容保留为真实来源核查记录。

行业字典提供了名称为“沪市港股通”“深市港股通”的板块编码。使用其中沪市编码查询 2016-01-04 时，Wind 返回零错误码，但字段和数据均为空，未形成有效历史快照。对照已知全 A 板块查询能够返回历史成分，另一种编码长度的候选查询仍为空。

原因尚未确定：数据库字典编码与 API 编码的映射、历史板块可用范围等需要可靠说明，不能猜测。请求和失败结构保存于 `data_cache/preparation/connect_daily/failure.json`。收集器拒绝空结构、错误返回日期、非香港代码和重复代码。不会用当前名单或两次快照之间的猜测来构造历史资格。

仍需补齐和验收：南向历次可买和仅可卖资格、移出与退市历史成员行情、香港公司行动、结算汇率、历史费用和交易规则，以及证券生命周期与日历覆盖。整体保持 `research_ready=false`。
