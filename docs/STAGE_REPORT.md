## 一、摘要

本阶段将项目从"能跑回测的脚本集合"建设为**方法论对齐头部机构的研究平台**，并用它完成了一个完整的策略研究周期：假设 → 因子检验 → 组合构造 → 样本外验证 → 对冲分解 → 边界确认。

**核心成果**：
- 一个经过两段十年样本（2017-2021 / 2022-2026）验证的 5 因子选股组合
  （估值×3 + 规模 + 低杠杆），全市场 PIT 口径下相对等权对照的累计超额
  约 **+39pp / +62pp**（两段），4/5 年度不输等权
- **定性结论**：该组合是 smart beta（风格暴露工具），非全天候 alpha——
  收益约 2/3 来自风格 β，残差 alpha 仅一个年代为正
- 系统资产：108 项单元测试、三层数据源（零配额）、四层验证纪律、
  预注册验收制度、研究仪表盘

**最重要的方法论收获**：系统在真金白银之前否决了 7 个"看起来有效"的策略/因子。证据分级制度的可靠运转是本阶段最有价值的产出。

## 二、系统架构现状

### 2.1 数据层（三层数据源，`data/layered.py`）
```
① 本地 parquet 缓存（data_cache/，523MB）→ 零成本
② Wind Oracle DB（内网，无配额）→ K线不复权列/估值表/财务表/指数成分/一致预期
③ Wind 客户端 WindPy（有配额）→ 仅补 DB 缺口
```
- PIT 能力：时点全 A 成分（含退市股，2024 年点 5335 只中 102 只现已退市）、
  指数历史成分（AINDEXMEMBERS）、公告日财务（ANN_DT）、预期快照（EST_DT）
- 一次全市场（4685 只×5 年）全流程零配额，数分钟完成
- 历史教训：单日 3150 万条提取触发配额 → 催生本架构

### 2.2 研究层
| 模块 | 能力 |
|------|------|
| `research/factor_eval.py` | IC/RankIC/分层/换手率/单调性（函数型+矩阵型因子） |
| `research/risk_model.py` | 简化 Barra：风格暴露/中性化/因子收益（市值/动量/波动） |
| `research/overfitting.py` | Deflated Sharpe + 实验登记（TrialRegistry） |
| `data/fundamental_pit.py` | 公告日 PIT 财务因子（8 个注册） |
| `data/consensus_pit.py` | 一致预期 EPS 修正因子（稀疏覆盖 NaN 语义已处理） |

### 2.3 组合与验证层
| 模块 | 能力 |
|------|------|
| `portfolio/backtester.py` | 向量化 TopN 组合回测（印花税/滑点/涨跌停/换手统计） |
| `portfolio/optimizer.py` | cvxpy 凸优化（风险厌恶+换手惩罚+风格预算约束） |
| `portfolio/hedged.py` | β 对冲模拟（trailing β + 贴水成本） |
| walk-forward 框架 | 滚动样本外（因子选择无后视） |
| 消融框架 | 单因子/合成对照（组合级验收的唯一裁判） |

### 2.4 展示层
- webapp `/research`：时代×组合对比矩阵、净值/IC 曲线（ECharts）、因子贡献
- `/results`：全部研究报告归档；结构化 JSON 工件驱动

## 三、研究结论时间线（含全部否决）

| # | 假设 | 结果 | 教训 |
|---|------|------|------|
| 1 | akshare 超卖反弹有效 | **否决**（PIT 数据下 Q1 年化 +17%→0） | 幸存者偏差 ~17pp/年 |
| 2 | 无确认抄底（oversold_bounce） | 否决（胜率 17%） | 退市股是超卖尾部的主力 |
| 3 | MACD 金叉确认的超卖反弹 | 存活（+11.45%，夏普 0.64） | 右侧确认过滤崩塌股 |
| 4 | bp+size in-sample +8.3pp | **样本外未存活**（-2.1pp） | 追 trailing IR 的选择规则震荡 |
| 5 | 全市场宽度修复 | 部分成立（+73pp/+38.8pp 两段） | 窄池是主因，静态合成可行 |
| 6 | 300 指增形态 | **否决**（IR -0.56/+0.34 翻转） | 成分域破坏多因子互补宽度 |
| 7 | 中性化 ROE 进组合 | 否决（两段稀释 -6~-8pp） | 因子级 IC ≠ 组合级增值 |
| 8 | 一致预期修正进组合 | 否决（分裂判决） | 同上（第三次确认该规律） |
| 9 | 优化器+风格约束修复指增 | 否决（杀掉收益来源） | 与中性分解互证 |

**幸存者（生产合成，5 因子）**：ep + bp + sp + size(−) + leverage(−)

### 3.1 收益来源分解（Phase B 核心结论）
| 年代 | 多头收益 | 残差（对冲后） | 风格 β 贡献 |
|------|---------|---------------|------------|
| 2017-2021 | +28.6% | **-31.3%** | +60pp |
| 2022-2026 | +76.7% | **+25.0%** | +52pp |

### 3.2 多因子合成机制（消融实验结论）
单因子 Top100 全部弱或灾难（bp 单用 2022-26 为 **-47.7%**），合成 +76.7%——
alpha 来自**多因子 rank 合成的互补去噪**（避开每个维度的极端尾部），
不是因子收益的加总。

## 四、当前生产策略与证据链

**定义**：全市场 PIT 池（剔除上市<60日），5 因子 rank 合成，Top100 等权，月调仓，
滑点 0.1% + 印花税/过户费 + 涨跌停约束。

**证据链**（新 NaN 语义口径）：
| 年代 | 组合 | 等权对照 | 超额 |
|------|------|---------|------|
| 2017-2021 | +40.5%（夏普 0.44） | — | 见复检* |
| 2022-2026 | +65.4%（夏普 0.61） | — | 见复检* |
*4v5 一致性复检运行中；旧口径下 5 因子 vs 等权为 +38.8pp/+73pp。

**风险特征**：最大回撤 -27%~-44%；风格暴露（小盘+价值）是收益主力也是风险主力；
2018 型熊市无防守（-27.8%）。

## 五、边界与已知限制（诚实清单）

1. **残差 alpha 不跨期稳定**——真中性产品的核心缺口未解决；需要信息维度的
   变化（深度预期/另类/日内），而非更多日线可见因子
2. 风险模型 V1 无行业因子（SW 分类非 PIT）；协方差为收缩样本阵非因子结构模型
3. 期货以指数现货近似（未接主力连续与移仓/贴水实测）
4. Wind 估值字段存在少量回填风险（已标注 caveat）
5. 均权对照基准在 2022-26 口径下小幅漂移（+2.2% vs +3.4%，矩阵切片细节，待查）
6. 因子库仍以日线量价+财务比率为主，无日内/文本/事件类因子
