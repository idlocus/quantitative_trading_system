# 试炼 007：低波动异象（独立信号）

- 登记日期：2026-10-26 | 状态：待测 | 登记册编号：#7 | 类型：选股因子

## 1. 假设与经济理由
- 机械化：factor = 过去 60 交易日日收益标准差（低波好）；月末计算，
  全市场 PIT 池（同 005），十分位组合
- 经济理由：博彩偏好（lottery preference）资金系统性买贵高波动股，
  把低波股留在便宜处 → 风险调整后低波组合长期跑赢；机构考核短期化
  加剧拥挤高波。对手盘 = 追逐彩票型股票的资金
- 与 006 的关系：反转与低波同族（都做空"被追逐"），相关性需在组合
  分析时检验——本试验只做独立判据

## 2. 预注册判据（先写死）
- 组合：Q1（波动最低）− Q10（最高）价差，两期年化同号为正；
  成本后仍为正
- IC：月度 rank IC 均值 |t| ≥ 2（合并 t 主判据）
- 敏感性：波动窗 60/120/250 日三档同号
- 失败四类归因沿用模板

## 3. 预期
- 若有效：Q1−Q10 年化 +4% ~ +8%，且回撤显著小于市场（低波组合的
  定义性特征）；IC 可能偏小但稳定
- 噪音形态：仅牛市年份贡献（低波=防御 beta 而非异象）

## 4. 结果（2026-10-26 运行；5469 只股票，ST 过滤，118 个持有月）

- IC 全窗显著为正（低波排名确实预测收益），但十分位**价差两期翻号**
- 多头净超额 -6.6% ~ -12.3%/年（低波组合在基准含高飞股时跑输）

## 5. 结论与失效分析

- 结论：**007 FAIL（价差两期翻号）**
- 归因：**两期翻号（+ 截面与极端分裂）**
  - [x] IC 为正但 Q1−Q10 翻号：全体截面排序关系成立，而极端十分位
    被现代期微盘/高波动行情（2024-09 式小盘狂热）反复击穿——
    高波股的彩票行情在 2022-26 出现频率大增，低波组合持续踏空
  - 与 006 的关系：同为"逆拥挤"方向，但反转在两期都成立而低波
    只在旧年代成立——反转捕捉的是**短期行为过度**（可等待修复），
    低波承担的是**持续踏空成本**（高波狂热无期限）
- 注：IC 的稳健为正（t≈4）值得记录——若未来引入对冲工具或组合
  优化（低波做权重而非选股），此信息或有价值；按判据本试验关闭
